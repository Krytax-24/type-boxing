# Name ideas for Type Boxing

The game is not renamed. These are ideas to choose from. A quick web search found no game with an exact match for any of them, but a search is not a trademark check: look at the app stores, itch.io, Steam and the domain before committing.

What the name should say: a head to head fight, won by typing, with a sharp and slightly retro feel that fits the Terminal Arcade look.

| Name | Why it works | Watch out for |
|---|---|---|
| Counterstroke | A keystroke is a stroke, and the game has counters. Reads as a fighting game. | Sounds a bit like Counter-Strike. |
| Hard Return | The Enter key and a hard hit. Memorable and a little funny. | Not obviously a fighting game on its own. |
| Keyclash | Short, clear: keys clash. | Many small games use "key" names. |
| Backspace Brawl | Plays on the key you use most. | Longer, less serious. |
| Home Row Heroes | Warm, friendly, good for a portfolio. | Sounds like a teaching game. |
| Type Fighter | Says exactly what it is. | Generic; "Typing Fighter" already appears on game sites. |
| Capslock Clash | Loud and arcade like. | Two words starting with the same sound, fine, but long. |
| Wordstrike | Easy to say and spell. | Common word pair. |

Recommendation: Counterstroke for a serious look, Hard Return for personality. Keep "Type Boxing" as the subtitle while people learn the new name.
